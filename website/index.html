How it works

Three moves. No windows to open.

Chango waits quietly in the notification area until you need it. Then it's one gesture, wherever your files are.

Drag, then tap Shift

Start dragging files in File Explorer or on the desktop and keep holding. Tap Shift and the wheel opens around your pointer.

Let go on what you want

Drop on a format and the new file appears next to the original. The original is never changed.

Tap Shift for more

Each tap switches between Convert, Tools and Actions. Let go in the middle, or press Esc, to cancel.

Rather click? Select files and press Ctrl + Alt + Space. Or right-click and choose Chango. Changed your mind? Undo for a few seconds.

Private by design

Why upload a file just to change it?

Online converters take your file, process it on their server and hand it back. Chango does the same work on your own PC.

Online converters

  • Your file goes to someone else's server
  • Queues, waiting and file size limits
  • Accounts, ads, or a paywall after a few files
  • Nothing works without the internet

Chango

  • Your files never leave your PC
  • As fast as your PC, with no size limits
  • Free forever: no account, no ads
  • Works offline

Chango collects no personal data. Read the privacy policy; it's short.

No Office? Most things still work.

Images, media, subtitles, archives, CorelDRAW and PDF to PowerPoint, Excel or text are all built in. For Word, Excel and PowerPoint files, Chango uses Microsoft Office, or free LibreOffice if you'd rather.

Uses what Windows already has.

HEIC, AVIF, JPEG XL and RAW photos open with the codecs Windows provides. Install free FFmpeg and the extra video and audio formats appear on their own.

FAQ

Questions, answered.

Is Chango really free?

Yes. There's no trial, no limit on files, no ads and no paid tier. Chango is open source under the MIT licence, so anyone can read the code on GitHub.

Are my files uploaded anywhere?

No. Every conversion, edit and action runs on your PC. Chango doesn't send your files, their names or anything about you anywhere.

The only network request is an update check in the version from GitHub, which asks GitHub whether a newer version exists. You can turn it off in Settings → About. The Microsoft Store version makes no requests of its own. Details are in the privacy policy.

Which versions of Windows does it work on?

Windows 10 version 2004 (build 19041) or later, and Windows 11, on 64-bit (x64) PCs.

Do I need Microsoft Office?

Only for Word, Excel and PowerPoint files, and free LibreOffice works instead. Converting a PDF to Word needs Microsoft Word; PDF to PowerPoint, Excel, text or Markdown is built in. Images, video, audio, subtitles, archives and CorelDRAW files need nothing extra.

What is FFmpeg for?

FFmpeg is a free media tool. With it installed, Chango adds more formats: MKV, WebM, MOV, AVI, OGG, Opus and AIFF. Install it with winget install Gyan.FFmpeg; Chango notices it automatically.

What if I don't want to drag files?

Select files and press Ctrl + Alt + Space, then click an option. Or right-click files or folders in File Explorer and choose Chango.

Can I undo a conversion?

Yes. Every result can be undone for a few seconds after it's made, and undone files go to the Recycle Bin. Your original file is never changed in the first place.

Why does Windows SmartScreen warn me?

The downloads on GitHub aren't code-signed yet, so Windows doesn't recognise them at first. Choose More info → Run anyway. The Microsoft Store version is signed by Microsoft and doesn't show this warning.

Does it need administrator rights?

No. The installer installs Chango for your account only, and the portable version runs from any folder.

How do I uninstall it?

Go to Settings → Apps → Installed apps and uninstall Chango. To remove its settings and logs too, delete %APPDATA%\Chango and %LOCALAPPDATA%\Chango.

Is there a Mac version?

A native Mac app with the same drag, tap and let-go wheel is in development.

Who makes Chango?

Chango is made by Ramesh Tiwari. Its radial wheel is based on OrbitDrop by Mohammed Essam, shared under the MIT licence. Ideas and bug reports are welcome on GitHub or by email.
